# AI Job Tracker Automation

## Overview
An automated workflow that discovers remote jobs, evaluates them using AI, and organizes suitable opportunities into an Airtable CRM.

## Problem
Searching and filtering remote jobs manually takes hours.

## Solution
This workflow:
- Collects job listings
- Uses AI to evaluate job relevance
- Scores opportunities
- Stores qualified jobs in Airtable
- Helps track applications

## Tech Stack
- n8n
- OpenRouter API
- Airtable
- JSON
- Automation workflows
